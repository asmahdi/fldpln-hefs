## Setup

1. Clone the project in your computer

3. Create a new folder "data" inside the project folder

4. Copy the FLDPLN tiled library for Verdigris  
   `fldpln-hefs`  
   `|-- /data/lib/tile/verdigris [All tiles should be in this folder]`  
   `|-- (others..)`   

5. Install UV package manager if not installed (`pip install uv` should work)

6. open the project folder [fldpln-hefs] in terminal and run command `uv sync`. This will download necessary packages.

7. Now open the project folder in VSCode. 

8. Select the python environment from the project 
  <img width="610" height="136" alt="Screenshot 2025-12-06 at 12 09 36 AM" src="https://github.com/user-attachments/assets/e65d68c3-38b2-42e4-a4d9-c636fc35eca1" />


9. Now use main.py or leafmap_view.ipynb to run the program
