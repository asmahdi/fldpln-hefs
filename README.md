## Setup

1. Create a folder "data" inside the project folder

2. Copy the FLDPLN tiled library for Verdigris
   fldpln-hefs
   |-- /data/lib/tile/verdigris [All tiles should be in this folder]
   |-- (others..) 

4. Install UV package manager if not installed (`pip install uv` should work)

5. open the project folder [fldpln-hefs] in terminal and run command `uv sync`. This will download necessary packages.

6. Now open the project folder in VSCode. 

7. Select the python environment from the project

8. Now use main.py or leafmap_view.ipynb to run the program
